# Fitness Social Backend

Backend API for a location-based fitness partner discovery app.

## Features

- JWT Authentication
- User Profile System
- Geo-based Discovery Feed
- Swipe & Match System (WIP)
- Chat System (Planned)

## Tech Stack

- Node.js
- Express
- MongoDB
- Mongoose
- JWT
- Socket.io (planned)

## Project Structure

src/
config/
middleware/
modules/
auth/
users/
swipes/
connections/
utils/

## API Endpoints

POST /api/auth/register
POST /api/auth/login
PUT /api/users/profile
GET /api/users/feed

## Status

Backend MVP ~45% complete.
